Finds out what a browser-only Volti could do with Google Drive. Nothing here touches Volti's own data.

Setting up Google Cloud (once)
  1. In Google Cloud console, make a project.
  2. APIs & Services → Library: enable Google Drive API and Google Picker API.
  3. OAuth consent screen: External, publishing status Testing, and add your own Google account as a test user.
  4. Credentials → Create credentials → OAuth client ID → Web application. Authorized JavaScript origin: . Authorized redirect URI: . Copy the client ID (and the secret, for the second try below).
  5. Credentials → Create credentials → API key. Restrict it to the Google Picker API and to the website .
  6. The project number is on the console's dashboard (Project info).
